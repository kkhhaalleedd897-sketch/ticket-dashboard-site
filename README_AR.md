# لوحة تحكم التكت — نسخة أولية

هذه نسخة أولية قابلة للتشغيل محليًا لتصميم لوحة عربية داكنة، مع Flask API وتخزين SQLite. ليست نسخة إنتاجية مكتملة ولا تتصل ببوت ديسكورد تلقائيًا بعد.

## تشغيل محلي

1. استخدم Python 3.11 أو أحدث.
2. أنشئ بيئة افتراضية وثبت المتطلبات:
   ```bash
   python -m venv .venv
   # Windows PowerShell:
   .venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   python app.py
   ```
3. افتح `http://127.0.0.1:5000`.

الواجهة تعمل كمعاينة؛ عند عدم إعداد OAuth تحفظ الإعدادات محليًا داخل المتصفح فقط. مسار API محمي بتسجيل الدخول، وتحتاج عملية Discord OAuth الفعلية إلى استكمال تبادل الرمز وجلب السيرفرات والتحقق من MANAGE_GUILD/ADMINISTRATOR قبل الاستخدام الحقيقي.

## النشر والربط الحقيقي

- ارفع المجلد إلى مستودع Git خاص، ثم انشره على استضافة تدعم Flask/Gunicorn. الخطة المجانية وحدود النوم/التخزين تتغير لدى مزودي الاستضافة.
- أضف متغيرات `.env.example` في إعدادات الاستضافة، ولا ترفع ملف `.env` ولا تشارك Client Secret أو توكن البوت.
- في Discord Developer Portal أضف Redirect URL المطابق تمامًا لقيمة `DISCORD_REDIRECT_URI`.
- قبل الإنتاج، أكمل OAuth callback وطبّق تحققًا من صلاحيات المستخدم على السيرفر المختار لكل طلب كتابة، واستخدم قاعدة بيانات دائمة مشتركة.
- بوت Wispbyte يجب أن يجلب الإعدادات من `/api/bot/config?guild_id=SERVER_ID` مع ترويسة `X-Dashboard-Key`. أضف عنوان الخدمة والمفتاح إلى متغيرات البيئة السرية في Wispbyte ثم عدّل كود التكت ليطبّق الإعدادات. لا يُنصح باستخدام `default` في الإنتاج؛ استخدم Discord guild ID الحقيقي.
- لا يتم توليد Transcript افتراضيًا في إعدادات اللوحة. تأكد من أن كود البوت الحالي لا ينشئ transcript مستقلًا إذا أردت إيقافه نهائيًا.

## ملاحظات مهمة

- الواجهة وإدارة الأقسام ورتب الدعم تعمل كواجهة تفاعلية.
- هذه ليست بعد لوحة منشورة أو تكامل Discord OAuth مكتملًا. لا تعتبر الحفظ عبر API جاهزًا للإنتاج حتى يكتمل OAuth والتحقق من صلاحيات السيرفر.
- لا تضع توكن البوت في HTML أو JavaScript أو أي ملف عام.
